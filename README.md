# Jennifer Williams — React Portfolio

Модельное портфолио с основным форматом для телефона: 20 полноэкранных страниц, крупные фотографии, анимированная типографика и бесконечные свайпы. На широких экранах и в альбомной ориентации отображаются 10 журнальных разворотов — по две страницы рядом. Все заголовки, подписи, сетки, кнопки и наложения на обложке — настоящая React-вёрстка.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
```

Откройте http://localhost:4173/. Для готовой сборки:

```sh
npm run build
npm run preview
```

`dist/` можно разместить на обычном статическом хостинге. Серверная база данных, внешние ключи и платные сервисы для просмотра сайта не нужны.

## Управление

- Колесо вниз двигает развороты справа налево. Карусель бесконечна: после последнего разворота обложка въезжает справа, без перемотки.
- На телефоне можно тянуть вверх или влево. На компьютере можно перетаскивать фотографии.
- Биография раскрывается по разделам. На коротком экране её содержимое можно прокрутить, прежде чем перелистывать страницу.
- «О съёмке» открывает полное описание крупным шрифтом в панели, которую можно закрыть кнопкой или Escape.
- Мобильные кнопки имеют область нажатия минимум 44×44 px. Интерфейс учитывает вырез и нижнюю безопасную область телефона.
- Стрелки, Page Up / Page Down и пробел листают страницы. Кнопки внизу работают в обоих направлениях.
- Кнопка меню открывает оглавление. Его четыре главы кликабельны; на компьютере доступны также нижние индикаторы.
- Film повторно показывает вступление. «К портфолио» и Escape пропускают ролик. Звук включается отдельной кнопкой.
- В системе с включённым уменьшением движения вступление пропускается, а страницы сменяются без движения.

## Вступительный фильм

В комплекте готовые MP4 длительностью около 9,4 секунды, 30 кадров/с: 1920×1080 для широкого экрана и отдельный мобильный монтаж 1080×2340. Телефон загружает облегчённый вариант 720×1560 (1,07 МБ). В мобильном фильме один крупный портрет на кадр, титры размещены в безопасной области, переходы идут справа налево. Вертикальное видео показывается целиком на экранах с разными пропорциями. При повороте устройства версия фильма меняется с сохранением момента воспроизведения.

Это кодом созданная анимация фотографий и типографики с движением камеры, масками и переходами. Звук — оригинальная синтезированная композиция. По умолчанию браузер воспроизводит видео без звука.

Исходный рендер сохранён в `scripts/render-intro.py`; мобильная композиция — в `scripts/render-mobile-intro.py`. Для повторного рендера нужны Python, Pillow и NumPy; FFmpeg устанавливается с зависимостью `ffmpeg-static`.

```sh
python -m pip install Pillow numpy
python scripts/render-intro.py
python scripts/optimize-photos.py
npm run build
```

Чтобы пересобрать только телефонный фильм, выполните `python scripts/render-mobile-intro.py`.

## Где редактировать

- `src/spreads.jsx` — тексты и компоновка всех страниц, имя, параметры модели, биография и контактные подписи.
- `src/magazine.css` — журнальный дизайн страниц.
- `src/experience.css` — полноэкранный интерфейс и анимации появления титров.
- `src/mobile.css` и `src/MobilePages.jsx` — самостоятельная мобильная компоновка, дополнительные титры, биография и панель описания.
- `src/useInfiniteReader.js` и `src/carouselMath.js` — бесконечное движение и управление.
- `src/IntroFilm.jsx` — воспроизведение видео, звук, повторный просмотр и пропуск.
- `public/assets/generated/` — AI-фотографии, созданные специально для проекта встроенным ImageGen. Полные промпты сохранены в `image-prompts.md`.
- `public/assets/photos/` — WebP-фотографии, которые загружает сайт: весь набор весит 1,54 МБ вместо 21,10 МБ исходных PNG. Исходники сохранены для дальнейшего редактирования и рендера.
- `public/assets/fonts/` — локальный Cormorant Garamond и лицензия OFL.

Фотографии серий находятся на контактных листах. Компонент `Photo` выводит отдельный кадр из каждого листа; тексты и дизайн страниц остаются React-элементами. При замене серии важно сохранить текущую сетку 2×2 либо изменить геометрию `Photo.jsx`.

Имя Jennifer Williams, параметры и биография — демонстрационное наполнение из референса. Перед публичным использованием замените их на свои данные и контакты.

## Проверка

```sh
npm test
npm run build
```

Шесть тестов проверяют границы карусели, повторные циклы, обратное движение, непрерывность страниц и сохранение главы при смене телефонного формата на разворот. Дополнительно проверены все 20 мобильных страниц на экране 390×844, короткие экраны 375×667 и 320×568, разворот 1440×900, свайп, оглавление, описание съёмки и раскрывающаяся биография. Новый телефонный фильм проверен в браузере при 320×568, 390×844 и 430×932, включая поворот в 844×390 с сохранением момента, автозапуск, включение звука, повторный просмотр и пропуск. Все 282 кадра MP4 успешно декодированы FFmpeg. Когда карусель неподвижна, постоянный цикл анимации останавливается, чтобы экономить заряд.
